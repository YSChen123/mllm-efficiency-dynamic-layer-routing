# 可迁移验收

本文件在实际验收完成后写入命令与证据；未完成项不标为通过。验收环境与工作目录独立，不共享旧项目site-packages，不读取旧任务控制/验收JSON或私有Arrow索引。

验收包括：CPU单元测试；真实原图到预处理prefix/VQ、Full响应IDs、QK logits、五动作、KL、best/worst标签；至少一次真实optimizer更新；checkpoint恢复下一步；真实生成、预算及cache；官方SEED原图与旧缓存的完整对应检查。

同一原始权重和原始数据文件可在多个工作目录复用；这不等于依赖旧代码或旧训练状态。新服务器使用README的固定公开下载源和配置路径即可创建同样资源。

环境安装、干净目录全流程小测、训练/推理等价审计及完整指标的最终状态记录在本目录的JSON证据中。只有明确scope=FORMAL且全量记录、identity和hash通过的结果才计正式成绩；SMOKE_ONLY、诊断子集或未验证输出不能混报。
